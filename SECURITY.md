# Security and responsible use

This repository is a **ROS 2 research/simulation project** and includes no authenticated cloud services or remote control agent.

- Do not run the Gazebo/ROS launch files on a production robot without hardware-specific safety validation.
- The Collision Monitor demonstration is **not** a certified emergency-stop mechanism.
- Source files, downloaded dependencies, ROS bags and internal workstation logs are excluded from the public deliverable.
- No credentials or runtime tokens are required to inspect the offline evidence.
- Review third-party packages and the end-of-life Gazebo Classic dependency when reproducing on a new machine.

For private security concerns, open a private GitHub security advisory rather than publishing credentials or host diagnostics in issues.
